SAMURAI WARRIORS 2 (PC) - FRENCH TRANSLATION
============================================
(Français plus bas)

Full French translation of Samurai Warriors 2 (PC):
- menus, options and game screens;
- battle, Survival and Sugoroku text, unit names;
- duel lines, officer introductions, victory, retreat and death lines;
- Story mode: intros, character stories and endings;
- cutscene subtitles;
- stylized titles and interface images redrawn in French (story banners,
  victory and defeat screens...);
- game font extended to display French accents, with the right spacing
  (small SW2FrenchFont.asi plugin, in memory only).

Voices are unchanged (or Japanese with the "Japanese Voices" mod).
This mod contains no game files, only patches applied to your own copy.


THE 2 FILES
-----------
The mod comes in 2 files on Nexus. You need both:
- Installer: INSTALL.bat, UNINSTALL.bat, this readme, the patch tool
  (xdelta3) and the accent spacing plugin (SW2FrenchFont.asi, with
  dinput8.dll = Ultimate ASI Loader). It rarely changes.
- Patches: the translation itself. Each new version of the translation
  only replaces this file.
Both extract into the same SW2_French_Translation folder.


REQUIREMENTS
------------
- Samurai Warriors 2, English PC version, with no other mod changing
  sw2.exe or the linkdata folder (except the mods listed below).
- Some free disk space: the original files are kept so you can uninstall.


INSTALL
-------
1. Close the game.
2. Extract the 2 archives (Installer and Patches) into the game folder.
   You should get:
      ...\Samurai Warriors 2\sw2.exe
      ...\Samurai Warriors 2\SW2_French_Translation\INSTALL.bat
      ...\Samurai Warriors 2\SW2_French_Translation\patches\
3. Run SW2_French_Translation\INSTALL.bat.
If the game is in "Program Files": right-click INSTALL.bat,
"Run as administrator".
The installer checks all files first. If your version doesn't match,
it stops without changing anything.
It also copies SW2FrenchFont.asi next to sw2.exe (and dinput8.dll if you
don't have it yet; other mods using dinput8.dll keep working).


UPDATE
------
1. If Japanese Voices or Controller Mod are installed: run their
   UNINSTALL.bat first.
2. Extract the new Patches archive (and the Installer archive if it
   changed) into the game folder, overwriting the files.
3. Run SW2_French_Translation\INSTALL.bat: files show [UPDATE].
4. Run the INSTALL.bat of Japanese Voices / Controller Mod again.

From version 1.0 or 1.1 (old SW2_Traduction_FR folder): same steps. The
installer takes over the backup of the old folder; you can then delete
the SW2_Traduction_FR folder.


UNINSTALL
---------
Run SW2_French_Translation\UNINSTALL.bat (uninstall Japanese Voices and
Controller Mod first if they are installed). Do not delete the
SW2_French_Translation folder while the translation is installed: its
backup folder holds the original files.


COMPATIBILITY
-------------
- Widescreen Fix: works together, any install order.
- Japanese Voices and Controller Mod: install the translation FIRST. To
  update or remove the translation, uninstall them first, then run their
  INSTALL.bat again afterwards.


CHANGES
-------
1.4 - Accent spacing fixed ("traî née" -> "traînée", û/â/ç no longer
      stuck to the next letter): SW2FrenchFont.asi, installed by
      INSTALL.bat.
      Move list screens: labels redrawn at one size, no more pieces of
      neighbouring words; key legend "[1] : [J]" instead of "[1] é [J]";
      keyboard key names in French; "or" -> "ou".
1.3 - CONDITIONS in the battle pause menu in the same font as the other
      words.
1.2 - Sugoroku: event cards (Charity, Typhoon, Festival...), challenge
      results and the "press the button" message translated.
      Options: VIBRATION in the same font as the other words, ON/OFF and
      STEREO/MONO in French, brightness instructions translated.
      Save/load error messages translated.
      Mod split into 2 files (Installer / Patches), English file names.
1.1 - Missing texts translated: some Story mode battles, Survival
      missions, officer introductions, victory/retreat/death lines.
      Unit names. CONDITIONS/MISSION in the pause menu now use the same
      font as the other words.
1.0 - First release.

============================================
FRANÇAIS - TRADUCTION FRANÇAISE
============================================

Traduction complète en français de Samurai Warriors 2 sur PC :
- menus, options et écrans de jeu ;
- textes des batailles, du mode Survie et du Sugoroku, noms des unités ;
- répliques de duel, présentations des officiers, répliques de victoire,
  de retraite et de mort ;
- mode Histoire : introductions, histoires et fins des personnages ;
- sous-titres des cinématiques ;
- titres stylisés et images d'interface redessinés en français (bandeaux
  « Histoire de... », écrans de victoire et de défaite...) ;
- police du jeu complétée pour afficher les accents, avec le bon
  espacement (petit module SW2FrenchFont.asi, en mémoire uniquement).

Les voix restent celles d'origine (ou en japonais avec le mod
« Japanese Voices »). Ce mod ne contient aucun fichier du jeu :
uniquement des patchs qui modifient votre propre copie.


LES 2 FICHIERS
--------------
Le mod est en 2 fichiers sur Nexus. Il faut les deux :
- Installer : INSTALL.bat, UNINSTALL.bat, ce readme, l'outil de patch
  (xdelta3) et le module d'espacement des accents (SW2FrenchFont.asi,
  avec dinput8.dll = Ultimate ASI Loader). Il change rarement.
- Patches : la traduction elle-même. Chaque nouvelle version de la
  traduction remplace seulement ce fichier.
Les deux s'extraient dans le même dossier SW2_French_Translation.


PRÉREQUIS
---------
- Samurai Warriors 2 PC, version anglaise, sans autre mod modifiant
  sw2.exe ou le dossier linkdata (à part les mods listés plus bas).
- Un peu d'espace disque libre : les fichiers d'origine sont conservés
  pour pouvoir désinstaller.


INSTALLATION
------------
1. Fermez le jeu.
2. Extrayez les 2 archives (Installer et Patches) dans le dossier du jeu.
   Vous devez obtenir :
      ...\Samurai Warriors 2\sw2.exe
      ...\Samurai Warriors 2\SW2_French_Translation\INSTALL.bat
      ...\Samurai Warriors 2\SW2_French_Translation\patches\
3. Lancez SW2_French_Translation\INSTALL.bat.
Si le jeu est dans « Program Files » : clic droit sur INSTALL.bat,
« Exécuter en tant qu'administrateur ».
L'installeur vérifie d'abord tous les fichiers. Si votre version du jeu
ne correspond pas, il s'arrête sans rien modifier.
Il copie aussi SW2FrenchFont.asi à côté de sw2.exe (et dinput8.dll si vous
ne l'avez pas encore ; les autres mods qui utilisent dinput8.dll continuent
de fonctionner).


MISE À JOUR
-----------
1. Si la VO japonaise ou le mod manette sont installés : lancez d'abord
   leur UNINSTALL.bat.
2. Extrayez la nouvelle archive Patches (et l'archive Installer si elle a
   changé) dans le dossier du jeu, en remplaçant les fichiers.
3. Lancez SW2_French_Translation\INSTALL.bat : les fichiers affichent
   [MISE À JOUR].
4. Relancez le INSTALL.bat de la VO japonaise / du mod manette.

Depuis la version 1.0 ou 1.1 (ancien dossier SW2_Traduction_FR) : mêmes
étapes. L'installeur récupère la sauvegarde de l'ancien dossier ; vous
pouvez ensuite supprimer le dossier SW2_Traduction_FR.


DÉSINSTALLATION
---------------
Lancez SW2_French_Translation\UNINSTALL.bat (désinstallez d'abord la VO
japonaise et le mod manette s'ils sont installés). Ne supprimez pas le
dossier SW2_French_Translation tant que la traduction est installée : son
dossier backup contient les fichiers d'origine.


COMPATIBILITÉ
-------------
- Correctif écran large : fonctionne ensemble, ordre indifférent.
- VO japonaise et mod manette : installez la traduction AVANT. Pour mettre
  à jour ou retirer la traduction, désinstallez-les d'abord, puis relancez
  leur INSTALL.bat ensuite.
